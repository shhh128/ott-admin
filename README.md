# 🎬 OTT Admin

React, TypeScript, Supabase를 활용해 OTT 콘텐츠를 관리할 수 있도록 제작한 개인 프로젝트입니다.

콘텐츠 검색부터 등록과 삭제까지 관리자가 사용하는 화면과 기능을 구현하고 있습니다.

## 📌 프로젝트 정보

* 제작 기간: 2026.07 ~ 진행 중
* 개발 형태: 개인 프로젝트
* 배포 상태: 배포 예정

## 🛠 기술 스택

* Frontend: React, TypeScript, HTML, SCSS
* Backend: Supabase
* Chart: Chart.js, react-chartjs-2

## 🧩 주요 기능

### 로그인

* 이메일과 비밀번호를 이용한 로그인
* 로그아웃
* 로그인 여부에 따른 관리자 페이지 접근 제한

### 대시보드

* 콘텐츠 및 회원 현황 카드
* 콘텐츠 종류와 공개 상태를 보여주는 차트
* 가입자 추이 차트

※ 대시보드의 수치와 차트는 샘플 데이터로 구성했으며, 실제 데이터와의 연동은 준비 중입니다.

### 콘텐츠 관리

* 전체·시리즈·영화별 목록 조회
* 제목·장르·상태 검색
* 종류·상태 필터
* 등록일·공개일·제목 기준 정렬
* 페이지네이션
* 콘텐츠 등록 및 입력값 검사
* 장르 다중 선택
* 썸네일·배너 이미지 업로드 및 미리보기
* 콘텐츠 개별 선택 및 전체 선택
* 선택한 콘텐츠 삭제
* Supabase를 이용한 데이터 저장 및 조회
* 등록·삭제 결과의 목록 반영

### 준비 중인 기능

* 콘텐츠 수정
* 배너 관리
* 공개 요청 콘텐츠 관리
* 회원 관리
* 대시보드 실제 데이터 연동

## 🎯 문제 해결

### 콘텐츠 목록의 썸네일 로딩 개선

콘텐츠별로 Supabase Storage의 서명 URL(Signed URL)을 개별 요청하면서 썸네일 로딩이 지연되는 문제가 있었습니다.

이미지 경로를 배열로 모아 서명 URL을 일괄 발급받고, 반환된 경로와 URL을 각 콘텐츠에 연결하도록 변경했습니다.

이미지 주소 조회에 필요한 API 요청 수를 줄였으며, 변경 후 목록의 썸네일이 이전보다 빠르게 표시되는 것을 확인했습니다.

### 로그인 여부에 따른 관리자 페이지 접근 제어

로그인하지 않은 사용자가 주소를 직접 입력해 관리자 페이지에 접근하지 못하도록 처리해야 했습니다.

로그인 상태를 확인해 인증된 사용자에게만 관리자 화면을 보여주고, 로그인하지 않은 사용자는 로그인 페이지로 이동하도록 구성했습니다.

## 📘 배운 점

* TypeScript로 콘텐츠 데이터와 컴포넌트에서 사용하는 값의 타입을 정의해보았습니다.
* Supabase를 활용해 인증, 데이터베이스, 이미지 저장 기능을 연결했습니다.
* 검색·필터·정렬·페이지네이션을 함께 적용하며 목록에 표시할 데이터를 처리하는 방법을 익혔습니다.
* 등록·삭제 요청의 결과를 화면에 반영하며 데이터베이스와 화면의 상태를 맞추는 과정을 경험했습니다.
* 로그인 여부에 따른 화면 접근 제한과 데이터 접근 권한을 구분해 설정하는 방법을 학습했습니다.
